# 5C.3.1 - GXShield compatibility and tutorial reset

`POST /latest/api/index.php/gxshield/scanrisk` is a trusted-server telemetry sink. It returns a normal World Flipper MessagePack envelope and does not store risk data, flag, suspend, or delete a player.

## Reset one device/account for tutorial testing

Stop Starpoint first. The reset deletes the selected player's entire account, including sessions and save data, after creating a consistent SQLite backup under `var/backups`:

```powershell
pnpm player:reset-tutorial -- --player-id 2 --confirm-delete-account
```

For a non-default database:

```powershell
pnpm player:reset-tutorial -- --player-id 2 --database .\var\database\world-flipper.db --confirm-delete-account
```

Then clear the World Flipper app data on the device and relaunch. This forces a new `loginDevice` and `/tool/signup`; deleting only the `players` row can leave the client holding an old viewer session and cause `/load` to fail.
